Backend działa w trybie API + WebSocket. Obsługa stron HTML została przeniesiona do aplikacji React.

Channel Layer: InMemory (Development)

🔌 REST API Endpoints

Endpointy obsługiwane przez views.py i dostępne dla aplikacji React.

POST /api/generate/ Proxy do Ollama (Generowanie tekstu)
POST /api/rag/ RAG Pipeline (NLP -> Komendy Robota)

⚡ WebSocket (Real-time)

WS /ws/chat/ Sygnalizacja WebRTC, Czat, Telemetria

Pełny adres dla klienta:

ws://127.0.0.1:8000/ws/chat/

  • http://localhost:5173 (Vite Default)
